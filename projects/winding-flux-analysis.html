01 / 04

Le problème : passer du bobinage à son effet physiqueThe problem: connect a winding to its physical effect

Un dessin de bobinage ne suffit pas à comprendre le champ qu’il produit. L’objectif du projet est de suivre cette relation dans un même outil : configurer, calculer puis visualiser.A winding drawing alone does not explain the field it produces. The project follows that relationship in one tool: configure, calculate, then visualise.

Dans ce projet d’équipe, nous avons développé une application Python/PyQt5. La première interface permet de choisir les encoches, les paires de pôles, le pas de bobine et le nombre de couches. Elle vérifie la faisabilité du bobinage et dessine la répartition des phases dans le stator.In this team project, we developed a Python/PyQt5 application. The first interface sets slots, pole pairs, coil span and layers. It checks winding feasibility and draws the phase arrangement in the stator.

L’étude se poursuit avec les dimensions de la machine : rayons, entrefer et géométrie des encoches. Le bobinage définit où se trouvent les conducteurs ; la géométrie définit le chemin dans lequel le flux pourra circuler.The study continues with machine dimensions: radii, air gap and slot geometry. The winding defines conductor placement; the geometry defines the paths through which flux can travel.

02 / 04

La solution : de la FMM au système à résoudreThe solution: from MMF to the system to solve

Chaque étape prépare la suivante : les courants créent l’excitation, le maillage représente la machine et le solveur relie les deux.Each stage prepares the next: currents create excitation, the mesh represents the machine, and the solver connects them.

  1. 01

    Calculer la force magnétomotrice — FMMCalculate magnetomotive force — MMF

    La disposition des bobines, le nombre de spires et les courants donnent la contribution de chaque phase. Leur somme produit une FMM résultante : l’excitation magnétique appliquée aux dents de la machine.Coil placement, turns and currents determine each phase contribution. Their sum gives the resultant MMF: the magnetic excitation applied to the machine teeth.

  2. 02

    Découper la machine en cellulesDivide the machine into cells

    Le maillage polaire représente le rotor, l’entrefer, les dents/encoches et la culasse. Dimensions et matériaux donnent les réluctances entre cellules : elles décrivent la résistance au passage du flux.The polar mesh represents the rotor, air gap, teeth/slots and yoke. Dimensions and materials determine reluctances between cells: how strongly each path opposes magnetic flux.

  3. 03

    Assembler et résoudre Ax = bAssemble and solve Ax = b

    A décrit les liaisons du réseau de réluctances ; b contient l’excitation issue de la FMM. La résolution donne x, les potentiels magnétiques des cellules. Ces valeurs permettent ensuite de calculer les flux entre cellules.A describes connections in the reluctance network; b contains the excitation derived from MMF. Solving gives x, the cell magnetic potentials. These values then allow fluxes between cells to be calculated.

Les choix de calculCalculation choices

La discrétisation utilisée ici est un réseau de réluctances sur une grille polaire. La FMM calculée par dent est reportée sur ce réseau. NumPy organise les données et SciPy résout le système creux par gradient conjugué préconditionné.The discretisation used here is a reluctance network on a polar grid. Tooth MMF is mapped onto that network. NumPy organises the data and SciPy solves the sparse system with preconditioned conjugate gradients.

03 / 04

Le résultat : du flux à une lecture en 2DThe result: from flux to a 2D interpretation

Une fois les potentiels connus, l’application retrouve le flux Φ, puis l’induction magnétique B. Les deux vues aident à comprendre où passe le flux et où le champ est le plus intense.Once potentials are known, the application derives flux Φ and then magnetic flux density B. Two views show where flux travels and where the field is strongest.

  1. 01

    Déduire les flux entre cellulesDerive fluxes between cells

    Les différences de potentiel magnétique, les sources de FMM et les réluctances donnent le flux de chaque branche. Les lignes reconstruites rendent son trajet lisible dans la coupe de la machine.Magnetic-potential differences, MMF sources and reluctances give the flux in each branch. Reconstructed lines make its path visible in the machine cross-section.

  2. 02

    Calculer B et afficher la carteCalculate B and display the map

    Le flux rapporté aux sections traversées donne les composantes de B. La carte de couleurs affiche son intensité dans la géométrie : on relie ainsi un choix de bobinage à un résultat physique visible.Flux divided by the traversed cross-sectional areas gives the components of B. The colour map shows its magnitude within the geometry, connecting a winding choice to a visible physical result.

Les choix de calculCalculation choices

Les captures proviennent de l’application, avec un même jeu de paramètres. Le modèle est une coupe 2D à perméabilités imposées ; la saturation n’est pas calculée. Une comparaison avec FEMM peut compléter l’étude, sans constituer un essai sur machine physique.The captures come from the application using one parameter set. The model is a 2D cross-section with prescribed permeabilities; saturation is not calculated. A FEMM comparison can complement the study, without constituting a physical machine test.

Ce que ce projet démontreWhat this project demonstrates

Relier une question d’électrotechnique à un outil Python utilisable : des entrées compréhensibles, une chaîne de calcul cohérente et des résultats que l’on peut interpréter.Connect an electrical-engineering question to a usable Python tool: clear inputs, a consistent calculation pipeline and results that can be interpreted.

Ce travail d’équipe met en pratique la programmation orientée objet et la séparation entre interface, calcul et visualisation. C’est cette continuité — du paramètre saisi au résultat expliqué — qui donne sa valeur à l’application.This team project applies object-oriented programming and separates the interface, calculation and visualisation. That continuity, from an input parameter to an explained result, gives the application its value.
