01 / 04

Le problème : passer du bobinage à son effet physiqueThe problem: connect a winding to its physical effect

Un dessin de bobinage ne suffit pas à comprendre le champ qu’il produit. L’objectif du projet est de suivre cette relation dans un même outil : configurer, calculer puis visualiser.A winding drawing alone does not explain the field it produces. The project follows that relationship in one tool: configure, calculate, then visualise.

Dans ce projet d’équipe, nous avons développé une application Python/PyQt5. La première interface permet de choisir les encoches, les paires de pôles, le pas de bobine et le nombre de couches. Elle vérifie la faisabilité du bobinage et dessine la répartition signée des conducteurs dans le stator. Le dessin et le calcul utilisent la même matrice de connexions ; chaque retour de bobine porte le courant opposé au côté aller, au pas choisi.In this team project, we developed a Python/PyQt5 application. The first interface sets slots, pole pairs, coil span and layers. It checks winding feasibility and draws the signed conductor arrangement. The drawing and calculation use the same connection matrix; each coil return carries the opposite current at the selected span.

L’étude se poursuit avec les dimensions de la machine : rayons, entrefer et géométrie des encoches. Le bobinage définit où se trouvent les conducteurs ; la géométrie définit le chemin dans lequel le flux pourra circuler.The study continues with machine dimensions: radii, air gap and slot geometry. The winding defines conductor placement; the geometry defines the paths through which flux can travel.

02 / 04

La solution : de la FMM au système à résoudreThe solution: from MMF to the system to solve

Chaque étape prépare la suivante : les courants créent l’excitation, le maillage représente la machine et le solveur relie les deux.Each stage prepares the next: currents create excitation, the mesh represents the machine, and the solver connects them.

  1. 01

    Calculer la force magnétomotrice — FMMCalculate magnetomotive force — MMF

    La matrice signée donne les ampères-tours par encoche. Leur cumul construit une fonction de bobinage constante dans les dents et linéaire dans les encoches. La vue instantanée applique les courants triphasés à l’angle électrique Wt ; la résultante est leur somme. La vue des références de crête permet de comparer les formes de chaque phase.The signed matrix gives the ampere-turns in each slot. Their cumulative sum builds a winding function that is constant in teeth and linear across slots. The instantaneous view applies the three-phase currents at electrical angle Wt; the resultant is their sum. Peak-reference mode compares the individual phase shapes.

  2. 02

    Découper la machine en cellulesDivide the machine into cells

    Le maillage polaire représente le rotor, l’entrefer, les dents/encoches et la culasse. Dimensions et matériaux donnent les réluctances entre cellules : elles décrivent la résistance au passage du flux.The polar mesh represents the rotor, air gap, teeth/slots and yoke. Dimensions and materials determine reluctances between cells: how strongly each path opposes magnetic flux.

  3. 03

    Assembler et résoudre Ax = bAssemble and solve Ax = b

    A assemble les conductances magnétiques entre cellules ; b contient l’excitation répartie dans la bande dents/encoches. La conservation du flux impose la somme des flux de branches à chaque nœud. Un potentiel de référence fixe la jauge ; le solveur creux donne les potentiels x, puis les flux signés sur les faces.A assembles magnetic conductances between cells; b contains excitation distributed through the tooth/slot band. Flux conservation balances branch fluxes at each node. One reference potential fixes the gauge; the sparse solver gives cell potentials x and then the signed face fluxes.

Les choix de calculCalculation choices

Le calcul est un réseau de réluctances sur une grille polaire. Les réluctances intègrent les chemins radiaux et angulaires ; les sources réparties sont cohérentes avec le courant axial homogénéisé utilisé dans FEMM. NumPy organise les données et SciPy résout le système creux par gradient conjugué préconditionné.The calculation uses a reluctance network on a polar grid. Reluctances integrate radial and angular paths; the distributed sources are consistent with the homogenised axial slot current used in FEMM. NumPy organises the data and SciPy solves the sparse system with preconditioned conjugate gradients.

Le résidu relatif du système est inférieur à 10⁻⁹ dans les trois cas comparés ci-dessous. Cela vérifie la résolution du système discret, sans mesurer à lui seul la fidélité du champ : celle-ci se vérifie par comparaison et raffinement.The relative system residual is below 10⁻⁹ in the three cases compared below. This checks the discrete-system solve; field accuracy still requires comparison and refinement.

03 / 04

Le résultat : du flux à une lecture en 2DThe result: from flux to a 2D interpretation

Une fois les potentiels connus, l’application retrouve le flux Φ, puis l’induction magnétique B. Les deux vues aident à comprendre où passe le flux et où le champ est le plus intense.Once potentials are known, the application derives flux Φ and then magnetic flux density B. Two views show where flux travels and where the field is strongest.

  1. 01

    Déduire les flux entre cellulesDerive fluxes between cells

    Les flux de faces servent à reconstruire le potentiel vecteur plan Az, avec continuité angulaire périodique et potentiel constant sur les frontières isolantes. Les lignes affichées sont des contours équidistants de Az : deux contours voisins délimitent le même flux. Le nombre de lignes règle la lecture de la carte.The face fluxes reconstruct planar vector potential Az, with periodic angular continuity and constant potential on insulated boundaries. Displayed lines are equally spaced Az contours: adjacent contours enclose the same flux. The line count controls how the map is read.

  2. 02

    Calculer B et afficher la carteCalculate B and display the map

    Les observations signées des faces opposées sont moyennées et rapportées aux sections physiques pour obtenir Br et Bθ. « Solve field » affiche directement la carte de |B| en teslas ; un clic dans la machine donne Br, Bθ et |B| dans la cellule choisie.Signed observations from opposite faces are averaged and divided by their physical areas to obtain Br and Bθ. “Solve field” directly displays the |B| map in tesla; clicking inside the machine reports Br, Bθ and |B| for the selected cell.

Les choix de calculCalculation choices

Les captures proviennent de l’application, avec un même jeu de paramètres. Le modèle est une coupe 2D à perméabilités imposées ; la saturation n’est pas calculée. Une interpolation dans les cellules préserve leurs flux de faces intégrés. La comparaison FEMM ci-dessous contrôle le champ signé, sans constituer un essai sur machine physique.The captures come from the application using one parameter set. The model is a 2D cross-section with prescribed permeabilities; saturation is not calculated. Interpolation preserves integrated face fluxes. The FEMM comparison below checks the signed field, without constituting a physical machine test.

04 / 04

Vérifier le champ avec FEMMCheck the field against FEMM

Un pic bien reproduit ne garantit pas une courbe correcte. L’audit du 12 novembre 2026 compare les deux composantes signées du champ dans l’entrefer et documente l’effet du maillage.Matching a peak does not guarantee the right curve. The 12 November 2026 audit compares both signed air-gap field components and documents the effect of mesh resolution.

La validation construit FEMM à partir du bobinage actif, des courants, de Wt, des dimensions, des perméabilités et de la longueur axiale. Le calcul tourne en arrière-plan ; les résultats apparaissent dans une fenêtre et FEMM reste ouvert sur la solution, avec légende |B|, contours de flux et lecture des valeurs par clic.Validation builds FEMM from the active winding, currents, Wt, dimensions, permeabilities and axial length. The solve runs in the background; a results window appears and FEMM remains open on the solution, with its |B| legend, flux contours and point-value inspection.

Les corrections ont porté sur le signe des retours de bobine, le placement physique des sources, les réluctances radiales et la reconstruction de B sur les faces opposées. Ce travail relie programmation, conservation du flux et vérification numérique ; les écarts restants sont montrés au lieu d’être résumés par le seul maximum.Corrections addressed coil-return signs, physical source placement, radial reluctances and B reconstruction from opposite faces. This connects programming, flux conservation and numerical verification; remaining differences are shown alongside the maximum.

Un même cas physiqueOne shared physical case

Cas comparé : 36 encoches, 4 pôles, pas 9, double couche, 204 spires, I = 2,8 A crête, Wt = 90°, ouverture d’encoche 5°, entrefer 1 mm et longueur axiale 110 mm. Les deux modèles imposent μr = 4 000 dans le fer, un courant axial homogénéisé dans les encoches et un flux normal nul au rayon d’arbre et à la frontière externe.Compared case: 36 slots, 4 poles, span 9, double layer, 204 turns, I = 2.8 A peak, Wt = 90°, 5° slot opening, 1 mm air gap and 110 mm axial length. Both models prescribe iron μr = 4,000, homogenised axial slot current and zero normal flux at the shaft radius and outer boundary.

Deux mesures différentesTwo different measurements

Pour chaque composante B, l’erreur de courbe est le RMS de (Bréseau − BFEMM) divisé par le RMS de BFEMM, sur tous les échantillons signés. C’est la norme L2 normalisée : les signes et les écarts locaux comptent, y compris près de zéro. L’écart du pic compare seulement les maxima de |Br| ; il ne mesure pas la forme de la courbe.For each component B, curve error is RMS(Bnetwork − BFEMM) divided by RMS(BFEMM), over all signed samples. This is the normalised L2 error: polarity and local differences count, including near zero. Peak error compares only the maxima of |Br|; it does not measure curve shape.

Ecourbe = 100 × √[Σ(Bréseau − BFEMM)² / ΣBFEMM²]Ecurve = 100 × √[Σ(Bnetwork − BFEMM)² / ΣBFEMM²]
